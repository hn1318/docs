## 下载页改为从 GitHub Releases 实时读取版本（无需重新构建）

- **背景**：站点是 `output: 'export'` 纯静态，没有服务端，所以由浏览器直接调用 GitHub REST API（`api.github.com` 带 CORS `*`），发布新 release 后刷新页面即显示。
- **`src/lib/github-releases.ts`**（客户端安全，无 window 副作用在模块顶层）：
  - `fetchReleases(repoUrl, limit=8)`：正则取 owner/repo → `GET /repos/{owner}/{repo}/releases?per_page=N` → 过滤 draft、规范化资产。
  - `sessionStorage` 缓存 5 分钟（key `makerstudio:gh-releases:<repoUrl>`），避免重复请求；8s AbortController 超时。
  - `API_BASES` 数组：默认只有 `https://api.github.com`，大陆访问慢时可加 CORS 代理作为兜底线路，代码无需改动。
  - 资产规范化：扩展名→format、文件名猜平台/架构、字节→MB、`digest`（`sha256:...`）→ sha256、按扩展名给默认双语 note、按 EXE<MSI<DMG<AppImage<ZIP 排序（保证第一行拿到「推荐」徽章）。
  - 任何失败（限流 60/h/IP、离线、无 digest、无资产）返回 `null` → 上层继续用内置数据。
- **`src/lib/downloads.ts`**：新增运行时视图模型 `AssetView`（sha256 可选）/`ReleaseView` 与 `bakedReleases(project)`（把构建期内置数据转成同一形状）；`mirrorHref` 入参放宽为 `{ file: string }`。
- **`src/components/downloads/releases-provider.tsx`**（client）：`ReleasesProvider` 挂一次，`useEffect` 里并发拉取所有项目的 releases，成功则替换；`mergeCurated()` 用内置数据里的文件名补回人工写的 note 与缺失的 sha256；导出 `useProjectReleases(key)`、`useNewestBuild()`。
- **组件拆分**：`ReleaseCard`（client，`release-card.tsx`）与 `BuildManifest`（client，`build-manifest.tsx`）从 `downloads-page.tsx` 移出，改从 context 取数据；卡片头部在实时数据生效时显示绿点徽章 `dict.downloads.liveSync`（GitHub 实时同步 / Live from GitHub），tooltip 用 `liveSyncHint`。`downloads-page.tsx` 保留为服务端壳（Hero/Web/Verify/Footer），外层包 `<ReleasesProvider>`。
- **SSR 兜底**：静态 HTML 里仍渲染内置清单（首屏不空、SEO 正常），水合后静默升级；无 JS 也能看到版本列表。
- **内置数据同步到 v0.3.0**（2026-11-05 发布，exe 1.71 MB / msi 2.46 MB，sha256 从 API 的 digest 取得），v0.2.0、v0.1 保留为历史版本。
- 构建：26 个页面通过；`out/downloads/index.html` 内含 v0.3.0 + sha；`out/_next/static/chunks/*.js` 内含 `api.github.com/repos` 与实时徽章文案。

## 经验

- 站点可用的 MDX 组件只有 fumadocs 默认集：`Card(s)`、`Callout`、`table`、`pre` 等（**没有 Steps / Accordion / Tabs**，至少本版本 `fumadocs-ui/mdx` 默认导出里没有），写文档时别用不存在的组件。
- 新增 MDX 页面不需要动 `source.config.ts` / `source.ts`，只需放文件 + 更新 `_meta.json`，构建时 fumadocs-mdx 自动重新生成 collections 与搜索索引。

## 经验（GitHub 实时版本）

- 客户端组件不能跨 server→client 边界接收 React 组件（如 lucide 图标函数），要么在 client 端自己 import，要么用 key 映射。
- 静态站做「免构建更新」：SSR/SSG 先渲染内置数据 → `useEffect` 拉远端 → `setState` 覆盖；请求失败必须静默回退，避免页面出现空白或错误态。
