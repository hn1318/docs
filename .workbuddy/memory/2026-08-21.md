## 中英文切换两处 Bug 修复（已验证）
- **Bug1 点击 English 不切换**：根因是 middleware 用 `getPreferredLocale()`（Accept-Language）覆盖了手动切换。修复：`src/middleware.ts` 加 `resolveLocale()`，先读 `locale` cookie，再回退 Accept-Language；`onLocaleChange` 写 `locale` cookie。验证：cookie=en + Accept-Language zh-CN → 留在 `/`(200)，不再跳 `/zh`。
- **Bug2 文本"English"换成图标并移到右侧**：移除 `src/lib/layout.shared.tsx` 链接数组与 `home-page.tsx` 页脚的 `switchLanguage` 文本链接（🌍+文本）。改用 fumadocs 内置 `I18nProvider`（`src/components/home/i18n-provider.tsx`，包 `HomeLayout`）+ 内置 `languageSelect` slot，自动在主题切换旁渲染 `lucide-languages` 图标（弹出 en/zh 选项，点击即切并写 cookie）。验证：navbar 含 `lucide-languages`(1)、主题切换(1)、页脚文本开关(0)。
- **验证方式**：`next dev -p 3211`（清理残留 PID 6928 及 node worker 后重启，避免 `.source/browser.ts` EPERM 锁）。curl 四项全过：`/`、`/zh` 均 200，cookie 优先逻辑正确，图标在位，文本开关已清除。
- **注意**：Next 16 警告 `middleware` 约定已弃用（建议 `proxy.ts`），目前仅警告、不影响功能；`src/middleware.ts` 仍生效。
