## 新增下载页 /downloads（中英双语）

- **导航**：`src/lib/layout.shared.tsx` 的 `baseOptions` 在 Documentation 之后插入 Downloads（`accent: 'nested-url'`）；首页导航为 Projects → Documentation → Downloads，文档页为 Documentation → Downloads。文案 `dict.nav.downloads`（Downloads / 下载）。
- **数据结构** `src/lib/downloads.ts`（核心扩展点）：
  - `DOWNLOAD_PROJECTS`：项目 → `releases[]`（版本、日期、channel、releaseUrl）→ `assets[]`（file、platform、arch、format、size、sha256、github 直链、双语 note）。
  - `MIRROR_ROUTES`：自建线路数组，**目前为空**；文件约定路径 `${base}/${project.key}/${version}/${file}`（`mirrorHref()` 生成）。加一条配置即所有资产自动多出一个线路按钮，页面无需改动。
  - `WEB_PROJECTS`：HWeather / NetTool / CampusTao，作为「无需安装」卡片（`webTitle`）。AutoClicker 为唯一有安装包的项目。
  - 现有真实数据来自 GitHub Releases：AutoClicker v0.2.0（2026-10-19，exe 1.77 MB / msi 2.58 MB）与 v0.1（2026-10-17），sha256 全部写入。
- **页面** `src/components/downloads/downloads-page.tsx`：Hero → 线路说明 banner → Release 卡片（assets 行含平台/架构/格式/大小/SHA-256 复制按钮 + GitHub 下载按钮 + 线路占位「即将上线」）→ `<details>` 历史版本 → 无需安装的产品卡片 → 校验说明（certutil 命令）→ 共享页脚。
  - `src/components/downloads/checksum-copy.tsx`：客户端复制完整 SHA-256（页面只显示前 16 位）。
- **共享页脚重构**：主页页脚抽成 `src/components/site-footer.tsx`（`SiteFooter({ locale })`，Resources 增加 Downloads 链接，保留 Status 状态胶囊）；主页项目数据抽到 `src/lib/home-projects.tsx`（`homeProjects`），home-page.tsx 与 site-footer 共用，避免循环引用。
- **路由**：`src/app/downloads/{layout,page}.tsx` + `src/app/zh/downloads/{layout,page}.tsx`，使用 HomeLayout + SiteI18n（语言切换按路径前缀互换，`/downloads` ⇄ `/zh/downloads`）。
- 构建：`NODE_OPTIONS= npx next typegen && NODE_OPTIONS= npm run build` → 26 个静态页，`out/downloads/index.html`、`out/zh/downloads/index.html` 生成；导航顺序、8 条 GitHub 下载直链、SHA-256、「即将上线」占位均已验证。

## 经验

- 新增顶层路由段（如 `/downloads`）后先跑 `npx next typegen`，否则 `LayoutProps`/`PageProps` 的 `LayoutRoutes` 约束会报错。
- 页面级 i18n 只需用 `SiteI18n` 包裹布局：切换语言时 `onLocaleChange` 会剥离/补回 `/zh` 前缀，保持在同一路径。

## 下载页 Hero 动态背景（参考 Fumadocs 但不同）

- 组件 `src/components/downloads/hero-aurora.tsx`，样式写在 `src/app/global.css` 末尾的 `hero-aurora*` 段（纯 CSS，无 JS/canvas）。
- 五层自后向前：① 三个径向渐变光云（teal/indigo/amber，`hero-aurora-drift` 23/31/27s alternate）② conic-gradient 弧环 + radial mask，`hero-aurora-spin` 52s 旋转 ③ 点阵 `radial-gradient(currentColor 1px)` + 对角漂移 `hero-aurora-dots` 20s ④ SVG feTurbulence 胶片颗粒（`mix-blend-mode: overlay`，steps(5) 抖动）⑤ 14s 光带扫过 `hero-aurora-sweep`；底部 `to-fd-background` 渐隐衔接下一屏。
- 与 Fumadocs 的差异：配色走本站青/靛/琥珀而非橙，纹理用漂移点阵+弧环而非静态半调球。
- 主题适配：`html:not(.dark)` 降不透明度、隐藏光带；≤640px 缩小弧环与模糊；`prefers-reduced-motion` 全部停动画。
- 教训：`.hero-aurora` 用 `isolation: isolate` 让 grain 的 overlay 只与本层混合，不污染页面其他元素。
