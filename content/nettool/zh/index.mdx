NetTool 是 **FRP（fast reverse proxy）** 的图形客户端。它不做穿透本身，而是负责：

- 下载并托管官方 `frpc` 核心
- 用可视化表单维护多套配置（服务器、令牌、一组隧道）
- 生成标准 `frpc.toml` 并拉起 / 停止进程
- **真实统计**每条隧道的上下行速率与累计流量（不是模拟数据）
- 直连 5 家 FRP 服务商的开放 API，登录后一键把远端隧道导入本地并启动

适合：临时把本机 Web 服务 / SSH / RDP / NAS 暴露到公网、调试微信回调、和朋友联机开服、管理多个服务商的隧道。

<Callout type="warn" title="NetTool 不提供服务器">
你需要一个 frps 服务端（自建），或直接使用 [第三方服务](/zh/docs/nettool/providers/) 里的服务商账号。
</Callout>

技术栈：Tauri 2 + Vue 3 + Rust，主要面向 Windows（安装包 / 免安装两种形式；macOS、Linux 可自行编译）。

## 从源码构建

```bash
pnpm install
pnpm tauri dev        # 开发模式（Vite + Tauri）
pnpm tauri build      # 打包安装包
pnpm dev              # 仅前端（Tauri API 不可用，仅调样式）
cd src-tauri && cargo test --lib   # 后端单元测试
```

主要模块：

- 前端：`src/`（Vue 3 + TS），页面在 `src/views/`，通用组件在 `src/components/`
- `runner.rs` 编排 frpc 进程、计量网关与采样
- `traffic.rs` 本地计量网关
- `config.rs` 配置渲染与解析（TOML / 旧版 INI）
- `providers/` 各服务商适配（`mod.rs` 为通用引擎）
- `settings.rs` 应用设置、存储目录、开机自启

新增服务商：在 `providers/` 下加一个子模块，实现 `login_key / user / tunnels / profile`，再在 `provider_metas()` 注册即可。
