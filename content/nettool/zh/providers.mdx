登录后可以读取账号信息、远端隧道列表，**预览配置 → 导入为本地配置 → 直接启动**。

| 服务商 | 登录方式 | 备注 |
| --- | --- | --- |
| **ME Frp** | 访问密钥 / 密码（需人机验证） | 支持签到领流量、禁用/启用、强制下线 |
| **OpenFrp** | 网页登录（推荐）/ 旧版 Authorization | 网页登录会自动轮询授权结果，无需手动复制 |
| **ChmlFrp** | 访问令牌（access_token） | 面板「用户中心」复制 |
| **SakuraFrp** | 访问密钥 | 需完成实名认证才有 API 权限 |
| **MSL Frp** | 用户 Token | 在 MSL 用户中心复制 |

## 通用流程

1. 顶部选服务商卡片 → 左侧登录（按服务商能力显示「网页登录 / 密钥登录 / 密码登录」标签）
2. 登录成功后左侧变成账号卡：用户组、隧道配额、流量、签到状态、带宽等
3. 右侧勾选隧道 → 「预览配置」看生成的 `frpc.toml`，或直接「导入配置」/「导入并连接」
4. 导入会新建一套带来源标签的配置，并自动切为当前配置

<Callout type="warn" title="同一批次必须在同一节点">
同一批次导入的隧道必须属于**同一个节点**（服务端要求），跨节点会提示分批导入。
</Callout>

## 各服务商登录要点

**ME Frp**

- 访问密钥即 API Token，在控制台账户设置里复制。
- 密码登录需要人机验证：点「打开验证页面」→ 浏览器完成验证 → 复制页面给出的 **Base64 验证码** → 粘贴回来（程序会自动解码）。
- 「签到」按钮在未签到时出现，同样需要粘贴验证码；签到成功后配额会刷新。

**OpenFrp**

- 面板已取消「复制 Authorization」入口，请用**网页登录**：点按钮 → 浏览器打开官方授权页 → 确认登录 → 程序每 5 秒检测一次，成功后自动登录；等待页可「取消」。
- 旧账号保存的 `OPENFRP...` 凭据仍可用「密钥登录」粘贴。

**ChmlFrp**

- 新版接口用 `access_token` 鉴权，旧参数 `token` 已失效；不支持密码登录。
- 文档写的是 `http://`，实际只有 HTTPS 可用，程序已内置正确地址。

**SakuraFrp**

- 用「账户信息 → 访问密钥」；未实名账号看不到该入口。

**MSL Frp**

- 用用户中心的 Token（`Authorization: Bearer`）。

凭据保存在本地 `providers.json`，可随时「退出登录」单独清除。

## 日志

- 级别筛选：`ALL / TRACE / DEBUG / INFO / WARN / ERROR`，每档显示条数
- 关键字搜索、自动滚动开关、清空、导出为 `frpc-logs-时间戳.log`
- 日志同时**按天落盘**：`{日志目录}/frpc-YYYY-MM-DD.log`，默认日志目录是 `{数据目录}/logs`

连接失败时优先看这里：frpc 的原始报错（如 `connect to server error`、`port already used`）比面板上的提示更具体。
