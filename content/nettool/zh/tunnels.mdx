## 隧道管理

支持 7 种代理类型，表单会按类型显示对应字段：

| 类型 | 必填字段 | 说明 |
| --- | --- | --- |
| `tcp` / `udp` | 远程端口 | 最常用；udp 适合游戏联机 |
| `http` / `https` | 自定义域名（逗号分隔）或子域名 | 走 frps 的 vhost，无远程端口 |
| `stcp` / `xtcp` | 密钥（secretKey） | 点对点加密隧道，访问方需同一密钥 |
| `tcpmux` | 自定义域名 | 复用单个端口的 HTTP 多路复用 |

通用字段：本地 IP、本地端口、加密（useEncryption）、压缩（useCompression）、带宽限制（bandwidthLimit）。

其他操作：

- **导入配置**：支持 TOML、旧版 INI、JSON 三种格式，可一次导入多条隧道。
- **复制 TOML**：把单条隧道渲染成 TOML 片段。
- **启用开关**：关闭的隧道不会写进 `frpc.toml`，重新连接后生效。
- **访问地址**：HTTP(S) 隧道在编辑弹窗底部会实时显示 `http(s)://域名`，可一键复制。
- 列表里会显示「未配置访问域名」的警告色提示——HTTP 隧道缺域名时启动会直接报错。

## 控制面板

### 面板内容

- 顶部：当前配置、**连接 / 断开**、**重置统计**、连接状态
- 四张指标卡：下行速率（含累计）、上行速率（含累计）、并发连接（含隧道数）、本次连接时长
- **实时流量**曲线：单位 KB/s，最近约 60 秒
- **隧道明细**表：隧道 / 类型 / 本地 → 远端 / 下行 / 上行 / 连接数 / 状态
- **运行信息**：frpc PID、生成的配置文件路径、本地管理接口端口、启用的统计网关数量
- 状态列来自 frpc 的 `/api/status`，能看到「运行中 / 等待回报 / 异常 + 错误原因」

### 流量是怎么算出来的

NetTool 在 frpc 与你的本地服务之间加了一层**本地计量网关**：

```text
外网用户 → frps → frpc → [NetTool 计量网关 127.0.0.1:随机端口] → 真实本地服务
                            ↑ 逐字节计数
```

- 启动时把隧道 `localPort` 改指向网关端口，网关再转发到真实的 `localIP:localPort`；
- 从 frpc 侧读到的字节记为**下行**，写回 frpc 侧的字节记为**上行**；
- 每秒结算一次速率，累计值在本次运行内累加，点「重置统计」清零。

两个已知边界：

- **UDP 隧道**没有方向可区分，界面标注「无字节统计」，速率显示为 0；
- 计量网关是额外一跳，延迟增加极小（本机回环），但请确保本地服务允许来自 `127.0.0.1` 的连接。
