左侧是可折叠导航，顶部有一条常驻工具条。

## 页面一览

| 页面 | 作用 |
| --- | --- |
| **控制面板** | 连接/断开、实时流量、每条隧道的速率与状态 |
| **隧道管理** | 当前配置下的隧道增删改、导入、启停 |
| **配置管理** | 多套配置的切换、复制、导入导出 |
| **第三方服务** | ME Frp / OpenFrp / ChmlFrp / SakuraFrp / MSL Frp 登录并导入隧道 |
| **核心下载** | 下载/校验 `frpc` 核心 |
| **设置** | 外观、存储位置、开机自启、关闭行为 |
| **日志** | 实时运行日志，筛选/搜索/导出 |
| **用户中心** | 本地资料与偏好（不会上传任何服务器） |
| **关于** | 版本与开源许可 |

顶部工具条（从左到右）：当前页面标题 + 当前配置名、运行状态灯（绿 = 已连接）、**连接/断开**、**刷新**、**日志**、**配置目录**、**亮/暗主题切换**。

## 配置管理（多配置）

一套「配置」= 服务器参数 + 令牌 + 一组隧道，用于区分不同服务端 / 不同服务商。

- **新建配置**：填名称、地址、端口、用户、令牌、传输协议（tcp/kcp/websocket）、TLS、日志级别。
- **编辑 / 复制 / 删除**：删除前会二次确认，且配置下的隧道会一并删除（至少保留一套）。
- **设为当前**：控制面板、隧道管理操作的都是「当前配置」；顶栏会显示当前配置名。
- **导出**：把该配置渲染成 `frpc.toml` 下载到本地。
- **导入 TOML**：粘贴完整 `frpc.toml`（含 `[[proxies]]`）或旧版 INI（`[common]` + `[隧道名]`），程序会解析出服务器参数与隧道并新建一份配置。
- **批量导出 / 批量删除**：勾选多套配置后统一处理。

来自第三方服务商的配置会带一枚来源标签（如 `ME Frp`），便于识别。

<Callout type="info" title="切换配置不影响正在运行的连接">
切换配置只改变「当前编辑的对象」，不会影响正在运行的连接；要让新配置生效，请回控制面板重新连接。
</Callout>
