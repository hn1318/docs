## 安装

- **安装包**：运行 `NetTool_x.y.z_x64-setup.exe`，按向导安装（可自选目录）。
- **免安装**：直接运行 `nettool.exe`。

<Callout type="info" title="当前版本">
v0.3.0 · 应用标识 `top.hn3.nettool`
</Callout>

### 从旧版本升级

应用标识为 `top.hn3.nettool`。如果你之前用过旧标识（`com.jlhan.nettool`）的版本，首次启动会自动把配置、核心、服务商登录凭据迁移到新目录，无需手动搬运。

### 首次启动

首次启动只做三件事：读取本地配置（没有就建一份默认配置）、确认 `frpc` 核心是否已安装、初始化系统托盘。

此时还不能连接——需要先装核心并填写服务器地址。

## 下载 frpc 核心

进入「核心下载」页：

| 区域 | 说明 |
| --- | --- |
| 版本列表 | 默认从 GitHub Releases 拉取真实版本；网络不通时提示「已切换为内置版本列表」，仍可下载 |
| 平台与架构 | 自动识别当前系统（windows / linux / darwin / freebsd × amd64 / arm64 / 386 / arm），也可以手动切换给别的机器下 |
| 下载并安装 | 多镜像自动回退，显示百分比与已下载/总量；下载后解压到数据目录并执行 `frpc -v` 校验 |
| 打开核心目录 | 直接定位到核心所在文件夹 |
| 已安装核心 | 显示路径、版本、平台、大小，可点「校验」确认可执行 |

核心文件存放：`{数据目录}/frp/frp_{版本}_{平台}_{架构}/frpc(.exe)`，元数据在同目录的 `core.json`。

## 五分钟跑通一条隧道

假设你要把本机 `127.0.0.1:8080` 的网站暴露出去：

1. **装核心**：进入「核心下载」→ 版本默认取最新 → 平台/架构已自动识别 → 点「下载并安装」。
2. **填服务器**：去「配置管理 → 新建配置」，填上你的 frps 信息后保存：
   - 服务器地址：你的 frps 域名或 IP
   - 服务器端口：默认 `7000`
   - 认证令牌：与 frps 的 `auth.token` 一致（没有就留空）
3. **建隧道**：去「隧道管理 → 新建」，填名称与转发目标：
   - 名称：`web`
   - 类型：`HTTP`（若服务端只开了 tcp 端口，选 `TCP` 并填远程端口）
   - 本地 IP/端口：`127.0.0.1` / `8080`
   - HTTP 隧道需填「自定义域名」（需已解析到 frps 并配置了 vhost）
4. **连接**：回到「控制面板」→ 点「连接」。绿色状态灯亮起即成功；失败会在页面顶部显示原因，同时「日志」页可看到 frpc 原始输出。
5. **验证**：用浏览器访问你的域名（或 `服务器IP:远程端口`），同时控制面板的「实时流量」曲线会动起来。

<Callout type="warn" title="改完要重新连接">
改了配置或隧道后，**需要重新连接**才会生效（工具不会自动重启运行中的 frpc）。
</Callout>

<Callout type="tip" title="不想自建 frps？">
可以直接登录第三方服务商，把远端已有隧道一键导入，见 [第三方服务](/zh/docs/nettool/providers/)。
</Callout>
