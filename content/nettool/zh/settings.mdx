## 设置

设置分四块。

### 外观

- 界面主题：深色 / 浅色
- 背景图片：JPG / PNG / WebP，本地压缩保存；显示方式（等比例铺满 / 完整显示 / 拉伸）、遮罩浓度 0–80%
- 圆角尺寸 0–24px、磨砂玻璃开关、模糊强度 0–60px
- 「恢复默认」一键还原

### 存储位置

- **数据存储位置**、**日志文件位置**可自定义（默认 `%APPDATA%\top.hn3.nettool`）
- 勾选「迁移现有文件」后点「应用存储位置」，会把现有配置 / 核心 / 凭据复制到新目录
- **重启后生效**（避免运行中数据分裂）；「打开数据目录」可直达

### 启动与关闭

- **开机自启动**（Windows 注册表 `HKCU\...\Run`）
- **关闭窗口时**：每次询问 / 后台运行 / 直接退出（详见下一节）

<Callout type="info" title="两处开关是联动的">
「用户中心 → 偏好设置」里的「开机自启动」「最小化到托盘」与这里联动，改任一处理结果一致（最小化到托盘 = 关闭行为设为「后台运行」）。
</Callout>

### 运行环境

显示 `frpc` 核心路径、版本、适用平台、应用标识，可「打开核心目录」。

服务器地址、令牌等连接参数不在这一页，请去「配置管理」编辑。

## 后台运行与托盘

关闭窗口时会弹窗询问：

| 选项 | 效果 |
| --- | --- |
| **后台运行** | 窗口隐藏到托盘，frpc 与隧道**继续运行** |
| **直接关闭** | 结束程序，同时停止 frpc 与计量网关 |
| **取消** | 什么都不做 |

勾选「记住我的选择」后不再弹窗；之后可在「设置 → 启动与关闭」里改回来。

托盘行为：

- **左键单击**图标 → 显示并聚焦主界面
- **右键菜单** → 「显示主界面」/「退出」（退出会先停掉隧道再结束进程）

如果托盘图标不见了，点任务栏右下角的 `^` 展开隐藏图标区找一下；Windows 11 默认会折叠新图标。

## 数据目录与文件

默认 `%APPDATA%\top.hn3.nettool`（可在设置中修改）：

```text
top.hn3.nettool/
├── settings.json        # 应用设置：关闭行为、自定义数据/日志目录
├── profiles.json        # 多套配置（当前配置 + 隧道列表）
├── providers.json       # 第三方服务登录凭据
├── core.json            # 已安装 frpc 核心的元数据
├── frp/                 # 下载的 frpc 核心
├── profiles/{配置id}/frpc.toml   # 每次连接时生成的运行配置
└── logs/frpc-YYYY-MM-DD.log      # 按天落盘的日志
```

备份 / 迁移：直接复制整个目录即可；换机时把目录拷到新机器同位置（或改设置指向它）就能恢复配置与登录状态。
