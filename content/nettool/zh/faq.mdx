---
title: 常见问题与排错
description: 按现象查原因与处理方式
---

| 现象 / 提示 | 原因与处理 |
| --- | --- |
| 「尚未安装 frpc 核心」 | 先去「核心下载」安装；或在设置里确认核心路径存在 |
| 「服务器地址 (serverAddr) 不能为空」 | 「配置管理 → 编辑」补上 frps 地址 |
| 「隧道「xxx」的本地端口未填写」 | 本地端口必须 > 0 |
| 「隧道「xxx」为 http 类型，需要填写自定义域名或子域名」 | HTTP(S) 隧道必须有域名；且域名要在 frps 配好 vhost 并解析到服务端 |
| 连接成功但访问不通 | 看「日志」里 frpc 的输出：`port already used` = 远程端口被占；`authentication failed` = 令牌不一致；`connect to server error` = 地址/端口/防火墙 |
| 改了配置/隧道没生效 | 需要断开后重新连接 |
| 第三方服务提示「不在同一节点」 | 分批次导入，每批只选同一节点的隧道 |
| OpenFrp 网页登录一直等待 | 授权页未确认或超时；点「取消」后重新发起（授权有效期由 OpenFrp 控制） |
| ME Frp 密码登录报验证码错误 | 必须在验证页完成后复制 **Base64 验证码**整段，程序会自动解码 |
| ChmlFrp 提示「缺少登录态 / 无效的登录状态」 | 用面板的 `access_token` 而不是旧 `token`；确认复制完整 |
| SakuraFrp 登录失败 | 账号需完成实名；访问密钥以「账户信息」页为准 |
| UDP 隧道没有速率 | 设计如此：UDP 无法区分方向，界面会标注「无字节统计」 |
| 托盘图标找不到 | 展开任务栏隐藏图标区；或任务管理器确认进程仍在 |
| 改了存储位置没生效 | 需重启应用（设置页有提示） |
| 杀毒软件报警 | 程序会调用 `taskkill` 结束 frpc、写注册表实现开机自启，可能被误报，放行即可 |

<Callout type="tip" title="找不到 frpc 的原始报错时">
「日志 → 导出」把文件发给服务商或开发者，定位最快。
</Callout>

<Callout type="info" title="文档版本">
本文档随代码迭代更新，对应 **v0.3.0**。发现与实际不符的地方，以应用内界面提示和「日志」页为准。
</Callout>
