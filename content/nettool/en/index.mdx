Welcome to the NetTool documentation.

NetTool is a quick-connect FRP tool for downloading, configuring and exposing tunnels in seconds.

## First Tunnel

1. Download NetTool and sign in
2. Pick a provider (FRP-compatible) and add your server
3. Create a tunnel — the config is generated for you

## Use Cases

- Expose a local dev server for testing
- Remote access to a home server
- Demo projects to clients without extra setup
