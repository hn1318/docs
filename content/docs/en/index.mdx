Welcome to the WebQ documentation! This guide will help you get started quickly.

## Getting Started

WebQ is a modern documentation platform built with Next.js and Fumadocs. It features AI-powered search, internationalization, and a great developer experience.

## Features

- **AI Search** — Ask questions in natural language and get instant answers
- **i18n** — Built-in support for English and Chinese
- **Fast** — Static generation for lightning-fast page loads
- **Customizable** — Tailor every aspect to your needs
