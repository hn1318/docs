点击标题栏的 ⚙ 进入设置页，分「通用」与「关于」两个标签。

## 通用

| 分组 | 选项 |
| --- | --- |
| **外观** | 主题（跟随系统 / 亮色 / 暗色）、语言（跟随系统 / 中文 / English） |
| **启动** | 开机自启（登录 Windows 后自动启动）、关闭按钮行为（每次询问 / 后台运行 / 直接退出） |
| **热键** | 开始/停止热键、紧急中止热键 |
| **更新** | 当前版本显示、更新源（留空默认读取 GitHub Release 最新版，也可填返回 `{ "version": "1.2.3" }` 格式的自定义 JSON 地址）、「检查更新」按钮，发现新版本可一键「前往下载」 |
| **存储** | 数据目录查看 / 更改 / 恢复默认 / 打开目录 |
| **配置备份** | 导出配置（保存为 `.json`）、导入配置（从 `.json` 恢复全部设置） |

## 关于

显示应用信息：版本、技术栈（Rust · Tauri v2 · Vue 3 · TypeScript）、点击注入方式（Win32 `SendInput`，物理像素）、许可证（MIT）。

## 系统托盘与关闭行为

关闭主窗口时的行为由 **设置 → 关闭按钮** 决定：

- **每次询问**：弹出对话框「退出，还是留在后台？」，可勾选「记住我的选择」不再打扰
- **后台运行**：窗口隐藏，程序驻留系统托盘，热键与正在进行的连点都不中断
- **直接退出**：立即结束程序

托盘操作：

- **左键单击**：恢复 / 隐藏主窗口
- **右键**：打开菜单，含「退出」

<Callout type="warn" title="托盘创建失败时的降级">
若托盘创建失败，「后台运行」会自动降级为直接退出，避免窗口藏起来却唤不回。
</Callout>

## 配置存在哪里

- 默认位置：`%APPDATA%\top.hn3.autoclicker`，核心文件为 `settings.json`
- **设置 → 存储 → 更改目录** 可把数据目录指到任意位置（如 U 盘、云盘同步目录），现有配置会**连同一起搬迁**；「恢复默认」切回原位置
- 目录指针固定存放在 `%APPDATA%\top.hn3.autoclicker\location.json`，因此无论数据目录改到哪里都能找回
- 写入采用「临时文件 + 重命名」的原子方式，写到一半崩溃也不会损坏配置

## 导入 / 导出

- **导出**：设置 → 配置备份 → 导出配置，选择保存路径生成 `.json` 文件
- **导入**：选择之前导出的 `.json` 恢复全部设置；允许文件缺少部分字段，缺失项使用默认值
- 从旧包名 `com.jlhan.autoclicker` 升级的用户：把旧目录的 `settings.json` 复制到新目录即可
