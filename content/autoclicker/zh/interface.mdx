---
title: 界面详解
description: 主界面上每一个控件的含义——点击、位置、高级设置与状态栏
---

主界面分为 **点击**、**位置**、**高级** 三个分组，底部固定状态栏与开始/停止按钮。

## 点击

| 选项 | 说明 |
| --- | --- |
| **点击间隔** | 两次点击之间的间隔，ms 与 Hz 双向换算，最小 1 ms |
| **点击次数** | 「无限」持续点击直到手动停止；「指定次数」到量自动停止 |
| **鼠标按键** | 左键 / 中键 / 右键 / X1 / X2（鼠标侧键） |
| **点击类型** | 单击 / 双击 / 按下保持 |
| **按住时长** | 仅「按下保持」可用，每次按下持续多少毫秒（1–10000 ms） |

## 位置

| 选项 | 说明 |
| --- | --- |
| **跟随光标** | 开启后每次点击都落在鼠标当前位置；关闭后使用固定坐标 |
| **坐标 X / Y** | 固定坐标模式下的点击位置。界面按**逻辑像素**显示，内部以物理像素存储，多显示器 / DPI 缩放场景下不会偏移。行内还会显示当前缩放倍率（如 `缩放 1.50×`） |
| **拾取坐标** | 点击后开始 3 秒倒计时，把鼠标移到目标位置，倒计时结束自动捕获并切换为固定坐标模式 |
| **鼠标跟踪** | 光标旁的实时坐标浮层，见 [热键与浮层](/zh/docs/autoclicker/hotkeys/) |

## 高级

### 节奏变化（间隔曲线）

| 模式 | 说明 |
| --- | --- |
| 恒定 | 固定间隔 |
| 线性加速 | 间隔从「点击间隔」逐步过渡到「结束间隔」 |
| 随机区间 | 每次间隔在「最小间隔」～「最大间隔」之间随机取值 |

### 抖动

| 选项 | 说明 |
| --- | --- |
| 间隔抖动 | 在实际间隔上叠加随机毫秒数，模拟真人节奏（0 表示不启用） |
| 坐标抖动 | 每次点击位置随机偏移 ±N 像素（0 表示不启用） |

### 时间控制

| 选项 | 说明 |
| --- | --- |
| 启动倒计时 | 开始前先倒数 0–10 秒 |
| 延迟开始 | 点开始后等 N 秒才真正启动（0 表示不启用） |
| 运行时长上限 | 运行满 N 秒自动停止（0 表示不启用） |

### 键盘连发

开启后不再模拟鼠标，而是按设定间隔**连发指定按键**（例如按住 `F` 连打）。点击类型、按键等规则同样适用。

### 前台窗口绑定

开启后只有当匹配的窗口位于前台时才执行点击，切走就自动暂停：

- **窗口标题**：前台窗口标题包含该关键字即匹配（留空则不按标题判断）
- **进程名**：如 `chrome.exe`（留空则不按进程判断）
- **读取当前窗口**：先切到目标窗口，3 秒倒计时后自动填充标题与进程名

## 状态栏

从左到右：

- **当前状态**——就绪 / 倒计时中（`将在 N 秒后开始`）/ 运行中
- **已点击次数**、运行时长、实际 CPS
- 右侧的 **开始 / 停止** 按钮

<Callout type="warn" title="运行中设置会锁定">
开始后主界面所有设置项变为不可编辑（顶部出现 🔒 提示）。这是设计行为：运行时使用的是按下开始那一刻的设置快照，避免界面修改与点击线程竞争。停止后即可重新编辑。
</Callout>

## 多点位序列

设置模型支持最多 **100 步**的序列：每一步可指定独立坐标、鼠标按键、点击类型、按住时长与步间延迟，并支持循环执行。开启 `sequenceEnabled` 后，引擎按步编排，适合「在多个位置轮流点击」的场景。
