Welcome to the HWeather documentation.

HWeather is a modern weather & disaster alert platform. This page gets you started in minutes.

## Quick Start

1. Open https://weather.hn3.top in any browser
2. Allow location access to get local weather instantly
3. Enable push alerts for earthquakes and extreme weather

## Key Features

- **Real-time weather** — temperature, air quality and forecasts
- **Disaster alerts** — earthquake & extreme weather push notifications
- **PWA** — install it like a native app on any device
